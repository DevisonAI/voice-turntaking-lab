# Optional — not the default

An earlier shortcut used OpenAI for STT+LLM+TTS with one key. That is **removed from the default live path**.

Default live stack is Deepgram + LLM + ElevenLabs so the portfolio matches ElevenLabs-class hiring screens.

If you need an OpenAI-only sandbox for personal debugging, add it as a separate `LIVE_PROVIDER=openai_bundle` later — do not conflate it with the hire proof.
